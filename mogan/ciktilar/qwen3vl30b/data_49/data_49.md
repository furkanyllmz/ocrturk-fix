 <h2>DEĞİŞİM ORANI:</h2> 
 <p>Yanda doğrusal olarak hareket eden bir hareketliye ait konum-zaman grafiği verilmiştir. Bu hareketlinin $t_0$. ve $t$. saniyeler arasında ortalama hızı; bu hareketlinin konumundaki değişimini, zamandaki değişime oranı ile hesaplanır.</p> 
 <ul> 
 <li>$V_{ort}$, bu hareketlinin $t_0$. ve $t$. saniyeler arasında ortalama hızı</li> 
 <li>$\Delta_x$, konumdaki değişimi</li> 
 <li>$\Delta_t$, zamandaki değişimi olmak üzere;</li> 
 </ul> 
 <div class="formula"><div>$$V_{\mathrm {ort } } = \frac { \Delta _ { x } } { \Delta _ { t } } = \frac { x ( t ) - x ( t _ { 0 } ) } { t - t _ { 0 } } \quad \mathrm { o l u r . }$$</div></div> 
 <p>Burada $\Delta_x$, $x$ bağımlı ($t$ ye bağlı) değişkenin değişimidir.</p> 
 <p>$\Delta_t$, bağımsız değişkenin değişimidir</p> 
 <p>Buna göre $V_{\mathrm {ort } } = \frac { \Delta _ { x } } { \Delta _ { t } }$ ifadesine <b>değişim oranı</b> denir.</p>
