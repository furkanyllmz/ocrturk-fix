# Boyutsal Homojenlik

## Example

$M_1$ ve $M_2$ kütleli, birbirinden $r$ uzaklıkta bulunan iki cisim arasındaki çekim kuvveti $F$, Newton'un çekim yasasından

$$F = \frac{GM_1 M_2}{r^2}$$

(G evrensel sabit) olarak verilir. Kütle sisteminde

$$[MLT^{-2}] = [G][M][M]/[L^2]$$

olup, buradan

$$[G] = [M^{-1}L^3 T^{-2}]$$

olur.
