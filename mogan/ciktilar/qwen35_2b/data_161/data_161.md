$$\frac { d P } { d t } = ( r - s P ) P$$

$$\text { Şekil: Lojistik denklemi'n faz düzlemi }$$

Parabol kesim noktaları $ P = 0 $ ve $ P = r / s $

$$( 0 , r / s ) \text { de } d P / d t > 0 ; ( t \rightarrow 0 \text { için } P ( t ) \text { artarak } r / s \text { ye yaklaşır ) }$$

$$( r / s , \infty ) \text { da } d P / d t < 0 \text { ( } t \rightarrow 0 \text { için } P ( t ) \text { azalarak } r / s \text { ye yaklaşır ) }$$
